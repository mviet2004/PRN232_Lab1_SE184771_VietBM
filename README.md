# PRN232 Lab 1 - Student Management API

## Technologies
- ASP.NET Core 8
- PostgreSQL
- Docker
- Swagger

## Run project

```bash
docker compose up --build
```

## Swagger URL

http://localhost:5000/swagger

## Database
PostgreSQL running in Docker container.

## Features
- CRUD Students
- Pagination
- Search
- Sorting
- RESTful API
